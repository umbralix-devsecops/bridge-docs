|===

[IMPORTANT]
====
El fallo más peligroso de una integración externa no es la caída, que es ruidosa y
evidente. Es la *degradación silenciosa*: respuestas `200` con datos incompletos.
Toda integración necesita al menos una métrica que detecte eso.
====
