[NOTE]
====
*Este índice solo enlaza documentos vigentes.* Las versiones superadas viven en el
`_historico/` de su sección y nunca se enlazan desde aquí.

Antes de leer nada más, pasa por xref:00_Estado_Actual.adoc[00_Estado_Actual] — es el
documento vivo que dice en qué punto está realmente el proyecto.
====

[IMPORTANT]
====
*Cambio de arquitectura del 2026-09-16.* Dos decisiones reescriben la premisa de toda la
documentación anterior:

* xref:11_gestion_producto/adr/adr-bs-005_servicio_unico.adoc[ADR-BS-005] — el Bridge Service
  *es* el backend del Portal de Videos. No hay un tercer servicio: el frontend Angular
  (`Sin-PortalVideos`, ya construido) llama a `/api` y quien responde es este servicio.
* xref:11_gestion_producto/adr/adr-bs-006_ingesta_por_empuje.adoc[ADR-BS-006] — nunca
  consultamos la base de datos de SinsaTools. Su microservicio de integraciones *empuja* el
  catálogo contra `POST /v1/ingest/catalog`, una API que publicamos nosotros.

Con ello desaparecen el `SyncWorker`, el `OnPremiseDbContext`, la conectividad con la red
corporativa y los endpoints `/v1/softwares`, `/v1/media/updates`, `POST /v1/sync` y
`GET /v1/sync/{syncId}`. Todo documento anterior a esa fecha que los mencione está superado.
====
